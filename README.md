### 📰 Fake News Detection System
Multi-modal fake news classifier using both text and image signals.
- **Text + Image pipeline**: BLIP-2 generates captions from images → SentenceBERT encodes caption + news text → FLAVA joint encoder fuses image-text → StandardScaler → XGBoost / Logistic / Random Forest classifier
- **OSINT pipeline**: NLP keyword extraction → DuckDuckGo search with image hash distance → TF-IDF vectorization → 300-tree Random Forest → confidence score 0–1
- Fact-checking kill switch against a hardcoded list of trusted domains
